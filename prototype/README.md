# Предварительный прототип сайта

`pogorelova-group-v2.html` — самостоятельный файл для визуального согласования. Скачайте его и откройте в современном браузере. Изображения, SVG логотипа № 57, шрифт, стили и сценарии встроены; запуск сервера и установка зависимостей не нужны.

Страницы внутри файла: главная, оценка, экспертиза, аудит, недвижимость, о группе и контакты. Меню и карточки переключают страницы через адрес после `#`. Внешние ссылки аудита и недвижимости открывают отдельные сайты.

Форма демонстрационная: данные не отправляются и не сохраняются. Проверять только на вымышленных данных. Выбор направления обновляет услуги. Закрытие формы очищает ввод.

Сохранены изображения из предоставленного прототипа, созданные ИИ. Они не изображают реальную команду. Услуги и описания — предварительные тексты для согласования, не подтверждение квалификации, географии или условий работы. Контакты сохранены из исходного прототипа.

Проверено в Chromium: семь страниц на ширинах 320, 390, 768 и 1440 px; отсутствие горизонтального скролла; четыре направления в первом экране главной и страниц направлений на мобильных размерах 320×740 и 390×844; мобильное меню; выбор услуг; проверки полей и имитация отправки; наличие внешних ссылок. При открытии прототип не выполняет внешних сетевых запросов. Доступность внешних сайтов этими проверками не подтверждалась.

Размещение на Timeweb/WordPress и подключение Bitrix24 — следующие этапы, в этот файл не входят.
