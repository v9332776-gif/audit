# Прототип v4: официальные сайты и карта

Самостоятельный файл `pogorelova-group-v4.html`; v3 сохранена.

В разделе аудита закреплена заметная карточка ООО «ПрестижАудит» с точным адресом из договора: https://xn--80aibejd7bikkfj.xn--p1ai/. В недвижимости — карточка Центра недвижимости «Эксперт», https://tppexpert.ru/. Ранее существовавшие внешние ссылки также сохранены. Все внешние переходы открываются в отдельной вкладке.

В контактах добавлена раскрываемая карта. Кнопка содержит «Показать офис на карте», Краснодар, ул. Монтажников, 1/4, БЦ SAS, офис 305. По умолчанию карта закрыта; iframe Яндекс Карт получает адрес загрузки после раскрытия. В общих контактных блоках ссылка ведёт к карте на странице контактов. Есть отдельная ссылка открытия адреса в Яндекс Картах. Адрес здания взят из имеющихся документов; офис не имеет отдельной метки. Геокодирование и точность показанной метки требуют визуального подтверждения.

Проверено в Chromium: 7 страниц на ширинах 320, 390 и 1440 px без горизонтального скролла; точные внешние адреса; карта закрыта и не выполняет сетевой запрос до раскрытия; раскрытие/закрытие мышью и клавиатурой; установка URL карты по нажатию. При тесте содержимое iframe подменялось тестовым ответом для проверки поведения загрузки. Реальная загрузка и положение метки не проверены: HTTPS-прокси среды возвращает 403 при обращении к yandex.ru. Это не свидетельствует о недоступности карты в браузере пользователя. Карта требует интернета; HTML и остальные встроенные материалы открываются без сервера.

Форма по-прежнему демонстрационная. WordPress/Timeweb и CRM не подключены.
