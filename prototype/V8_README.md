# Формы v8 — разные контакты звонков и мессенджеров

Основа: v7. Уточнены подписи и подсказки выбора канала связи:

- Телефон — номер для звонков.
- Telegram — актуальный номер, привязанный к Telegram, либо @username. Прямо указано, что номер может отличаться от номера для звонков.
- MAX — актуальный номер, привязанный к MAX, с таким же пояснением. Автоподстановка телефонного номера отключена для этого поля.
- Email — поле «Адрес электронной почты», type=email, autocomplete=email, пример name@example.ru и проверка формата.

Номера разных каналов не копируются друг в друга. Временный кэш внутри открытой формы сохраняет отдельные значения и очищается при закрытии. В payload номер MAX записывается только в contacts.max и не дублируется в contacts.phone как номер для звонков. Номер для звонков передаётся только при выборе канала phone. Поля относятся к предпочтительному способу связи.

Chromium: проверены разные значения для звонков, MAX и Telegram, подсказки, отсутствие автоматического копирования, username и номер Telegram, ошибочный/валидный email, переключение с восстановлением значений, структура payload и очистка. Ошибок JavaScript нет. Скриншот: previews/v8-messenger-contact.jpg.

Форма остаётся демонстрационной. Правильность формата не устанавливает существование аккаунта в мессенджере или доступность почты; рабочая доставка пока не подключена.
