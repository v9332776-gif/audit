# Сводная семантическая карта сайта

Актуальная текстовая карта: `Pogorelova_Group_Site_Semantic_Map_v6.xlsx` (7 октября 2026 года). Предыдущая v2 сохранена. Новая редакция не означает пересборку HTML. Подготовлен на основе исходной таблицы и обработанных пакетов Wordstat по аудиту, экспертизе и недвижимости.

Начать с листа «Страницы прототипа»: семь текущих страниц, проект URL WordPress, H1, Title, Description, блоки и CTA. Лист «Будущие посадочные» содержит предложения, а не утверждённое расширение договора. Для четырёх направлений подготовлены брифы; для оценки отдельно зафиксированы пробелы.

«Запросы и маршрутизация» содержит 5225 строк с происхождением. Это реестр наблюдений и чернового распределения, не 5225 уникальных коммерческих запросов. В широких выгрузках остаются нерелевантные, смешанные и информационные запросы. Назначение обзорной странице не является решением публиковать каждую строку. Прежде чем использовать запрос в тексте, проверить статус в исходной обработанной таблице, реальную услугу и поисковую выдачу.

Ключевые решения:

- Главная: оценка, экспертиза, аудит и недвижимость; консалтинг не пятое направление.
- Аудит: обязательный основной, инициативный дополнительный. Краткая страница группы и переход; полноценная коммерческая посадочная на официальном сайте отдельно от текущего объёма.
- Экспертиза: строительные и финансово-экономические исследования, судебные задачи, рецензирование. Услуги и процессуальный статус требуют проверки руководителем. Судебная задача не заменяет тип исследования.
- Недвижимость: подбор новостроек, города отдельно; квартиры, апартаменты и гостиничные объекты раздельно; цель покупки не тождественна типу объекта. Азовское побережье дополнительное. Названия проектов не подтверждают ассортимент.
- Оценка: исходные кластеры сохранены; цели и виды объектов подтверждаются. Транспорт и нематериальные активы не считаются проверенными только по наличию карточки в прототипе.

Выполнено: сопоставление источников, проект структуры, метаданных, блоков и FAQ; редакция самостоятельного HTML v3. Не выполнено: проверка поисковой выдачи, новые измерения частотности, подтверждение услуг/ассортимента, юридических фактов и контактов, перенос WordPress/Timeweb и производственная SEO-настройка. HTML с hash-переходами предназначен для визуальной оценки, не для поискового продвижения.

Частотности не складывать: пакеты, территории и фразы пересекаются. Время/регион/операторы сохраняются в источниках. Двойные кавычки в аудите подтверждены пользователем, несмотря на неоднозначный заголовок CSV; повторная выгрузка не требуется.

Далее: руководители проверяют брифы, реальные виды услуг и предложения; затем проверяется выдача для главных запросов, утверждаются посадочные и финальные тексты. Согласованные данные переносятся в WordPress с реальными URL, canonical, sitemap, robots, аналитикой и редиректами после выбора домена.
