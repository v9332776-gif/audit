# Клиенты — материалы для будущего портфолио

Источник: два скриншота блока «Клиенты» старого сайта business-yug.ru, предоставленные пользователем 6 октября 2026 года. Пользователь указал взять эти компании как клиентов, с которыми группа работала. Страница по сети не прочитана. HTML не изменяется, сборка и публикация приостановлены.

Оба скриншота показывают те же четыре логотипа в разном порядке. Четыре индикатора карусели не являются доказательством четырёх разных групп клиентов. Полнота списка не установлена; дополнительные названия не предполагаются.

## Решение для последующего сайта

- Предварительный блок «С нами работали» на главной и/или странице «О группе»; размещение после указания пользователя пересобрать сайт.
- Сохранять связь с историей группы «Бизнес-Юг». Не приписывать эти работы новому агентству недвижимости или ООО «ПрестижАудит» без данных об исполнителе.
- Не придумывать проекты, отзывы, показатели, даты, размер контрактов и результаты по логотипам.
- Для полноценного портфолио по каждой компании собрать: задачу, направление/услугу, период, исполнителя и результат, который можно раскрыть.
- Для размещения использовать чистые исходники логотипов; не вырезать и не растягивать низкокачественные изображения со скриншотов.

Статус: четыре названия прочитаны на скриншотах; пользователь подтвердил намерение использовать их как исторических клиентов. Подробности кейсов и точные юридические лица не установлены.
