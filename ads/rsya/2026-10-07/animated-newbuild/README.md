# Новостройки — анимированный баннер № 12

7 октября 2026 года. По просьбе пользователя создана анимированная версия идеи «Выбираете новостройку? → Подбор вариантов под ваш бюджет → Обсудить подбор». Референс движения — предоставленное видео 1080x1080_Push_App_v2.mp4. Персонаж, банковские тексты и маркировка из чужой рекламы не копировались.

## Файлы

- newbuild-300x600-html5.zip — пакет HTML5, index.html в корне, сцена и оригинальный векторный логотип внутри.
- newbuild-300x600.gif — самостоятельный анимированный GIF фиксированного размера.
- preview-300x600.mp4 — видео просмотра HTML5; не файл для загрузки в тип «Графическое объявление».
- preview-final.png — финальный кадр.
- html5-300x600/ — редактируемые HTML/CSS/JS и локальные ресурсы.
- preview.html — локальная страница просмотра обеих версий.
- manifest.json — точные размеры, длительности, вес и результаты проверки.

Распаковать ZIP и открыть index.html для просмотра HTML5. GIF можно открыть отдельно. ZIP содержит только необходимые для баннера файлы, без MP4, документации и внешних шрифтов.

## Анимация

Размер 300 × 600 px. Заголовок виден с начала. В HTML5 жилой комплекс плавно меняет положение и масштаб; карточка плана появляется и слегка движется; решение появляется снизу; у кнопки — один мягкий акцент. Анимации один раз проигрываются за 6 секунд и остаются на финальном кадре. Настройка reduced motion показывает финальную композицию без движения.

В GIF основная иллюстрация неподвижна для экономии веса, анимируются карточка плана, решение и кнопка. 61 кадр, 10 кадров/с, 6,1 секунды, без повторения. Оба рекламных файла проверены против присланного пользователем лимита: менее 512 000 байт, что также меньше 512 КиБ. Нет вспышек, резкого мигания, системных окон, полей ввода и фальшивых переключателей. CTA — рекламная кнопка.

Векторный логотип сохранен без изменения геометрии; в нижней полосе показываются исходные название и строка направлений, знак вне области полосы. Иллюстрация создана с ИИ, затем технически перекодирована в JPEG для экономии веса. Изображение показывает условный жилой комплекс, не конкретный объект продажи.

## Переход

В HTML5 предусмотрен вызов yandexHTML5BannerApi.getClickURLNum(1), если API доступен в среде размещения; URL подставляется в единственную кликабельную область. Для самостоятельного просмотра запасная ссылка — https://tppexpert.ru/. Для GIF конечную ссылку задают в Директе. Работа API проверена на тестовом объекте, не в рекламном кабинете. Подключение/доступность API и учет кликов проверить в валидаторе конкретного загрузчика; требования рекламной платформы могут отличаться.

## Проверено и что осталось

Проверено в Chromium: 300 × 600 без прокрутки, локальные изображения загружаются, нет ошибок JavaScript, текст и CTA присутствуют, анимации конечные, URL обновляется из тестового API. GIF проверен на размер, длительность и отсутствие бесконечного повтора. ZIP проверен на целостность и вес.

Официальные актуальные требования Яндекса из среды не подтверждены, результаты загрузки и модерации отсутствуют. Лимит 512 КБ принят из сообщения пользователя. Фактическое юрлицо рекламодателя, сведения для маркировки и конечная посадочная задаются при подготовке кампании. Чужой erid и рекламодатель из видео не переносились; новый erid не выдумывался. Утверждение о конкретной новостройке и её проектной декларации в баннере отсутствует. Баннер не опубликован, кампания не запущена.
